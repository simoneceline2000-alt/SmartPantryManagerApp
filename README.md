# SmartPantryManagerApp

##  Overview
SmartPantryManager is an Android application designed to help users manage pantry items and suggest recipes based on available ingredients. The goal is to reduce food waste and make meal planning easier.

## 🗄 Database Choice
- **SQLite** was chosen because:
    - It’s lightweight and built into Android.
    - Perfect for local storage without needing an internet connection.
    - Supports CRUD operations for pantry items and recipes.

## Features
- Add, edit, and delete pantry items.
- View pantry list with RecyclerView.
- Suggest recipes based on strict ingredient matching.
- View recipe details with layout binding.
- Settings screen with toggle options.
